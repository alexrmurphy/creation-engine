## The core rule: engine vs profile

- The **engine** is procedure any creator could use.
- A **profile** holds everything specific to one creator: voice pointers, standing rules, lexicon, forms, Notion page map.
- The engine never hardcodes a creator. Client content never goes into the engine.

## Where things live

- Live records and prose I edit are canonical in **Notion**.
- Skills, specs, schemas, templates, and scripts are canonical in **this repo**.
- Notion reference docs get snapshotted here for history.

## Principles

- One owner per thing.
- Spec before build.
- Name things once. The glossary is law.
- Human creation stays central, and automation earns its place.
- Log changes in `CHANGELOG.md`.
- Add complexity only when a real limit shows up.
